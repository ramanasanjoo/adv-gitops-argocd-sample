# adv-gitops-argocd

Production GitOps repository for Advantage CD.

Ownership:
- topology/: authoritative client/environment/cluster/database topology
- desired-state/: approved application release/image state only
- charts/: Helm deployment templates, maintained here (never generated by CI)
- argocd/: AppProjects and ApplicationSets
- applications/: runtime application catalog

Runtime applications:
- adv-admin
- adv-hr
- adv-fin
- adv-connect
- adv-insight
- adv-perbudget
